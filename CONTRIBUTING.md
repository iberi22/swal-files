# Contributing to SWAL Files

Thank you for your interest in contributing! Here is a brief guide on how you can contribute:

1. **Fork the repository**: Create your own fork of the project.
2. **Create a branch**: Make a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
3. **Commit your changes**: We follow Conventional Commits. Ensure your commit messages clearly describe your changes (e.g., `feat: add new feature`, `fix: resolve issue`).
4. **Run tests**: Before opening a Pull Request, verify that all tests pass by running `cargo test --workspace`.
5. **Open a Pull Request**: Submit your Pull Request against the `main` branch.
