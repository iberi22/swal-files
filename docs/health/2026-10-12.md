## 7. Top 5 fixes
1. **Remove `.gitcore/` Internal Files**
   - **Problem:** Internal business plans are exposed in a public repository.
   - **Evidence:** `find .gitcore -type f` lists multiple `.json` specification files.
   - **Proposed Change:** Add `.gitcore/` to `.gitignore` and run `git rm -r --cached .gitcore/`.
   - **Effort:** S
   - **Verification:** `git status` should not track `.gitcore/` files.
2. **Fix License Mismatch in README**
   - **Problem:** `README.md` incorrectly states MIT license while `LICENSE` is AGPLv3.
   - **Evidence:** `grep -ri "LICENSE" README.md` shows `Distributed under the **MIT License**.`.
   - **Proposed Change:** Update `README.md` to reflect the AGPLv3 license or change the `LICENSE` file if MIT was intended.
   - **Effort:** S
   - **Verification:** `grep -ri "License" README.md` reflects correct license.
3. **Remove False E2E Wayland Testing Claim**
   - **Problem:** `AGENT_INDEX.md` claims E2E Wayland screenshot tests exist, but they do not.
   - **Evidence:** `find tests -type f` reveals no visual or Wayland test suites.
   - **Proposed Change:** Remove the claim from `AGENT_INDEX.md` until such tests are implemented.
   - **Effort:** S
   - **Verification:** `grep -rin "Wayland" AGENT_INDEX.md` yields no results.
4. **Fix clippy warnings**
   - **Problem:** Codebase contains multiple `cargo clippy` warnings about redundant conditions and unneeded type casts.
   - **Evidence:** Running `cargo clippy --workspace` generates 11 warnings across crates.
   - **Proposed Change:** Run `cargo clippy --fix --workspace` and review changes.
   - **Effort:** S
   - **Verification:** `cargo clippy --workspace` exits with zero warnings.
5. **Optimize CI for PRs Only**
   - **Problem:** CI runs on all pushes to main/master, redundantly wasting compute resources on deployments.
   - **Evidence:** `.github/workflows/ci.yml` triggers on `push: branches: [ main, master ]`.
   - **Proposed Change:** Modify `.github/workflows/ci.yml` to trigger only on `pull_request`.
   - **Effort:** S
   - **Verification:** `grep "push:" .github/workflows/ci.yml` yields no results.
